# Changelog

All notable changes to this Cube. The format is [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the Cube uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html) — the version in
`cube.json` is the one the registry records, and a version can be released only once. Every
entry names its Linear issue.

## [0.1.0] — unreleased
